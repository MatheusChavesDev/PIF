a) O comando if (x = 0) atribui o valor 0 à variável x. Como o resultado dessa expressão de atribuição é 0, a linguagem C a avalia como falsa, e o bloco de código não será executado. Já o comando if (x == 0) realiza uma comparação lógica para verificar se x é igual a 0.   

b) Na Linguagem C, qualquer valor numérico diferente de zero (positivo, negativo, inteiro ou real) é avaliado como "verdadeiro". Um resultado é avaliado como "falso" apenas quando o seu valor é estritamente igual a zero (0 ou 0.0).

c) O bloco de código será executado. A instrução x = -5 atribui o valor -5 à variável, e como a expressão retorna esse valor diferente de zero, ela é avaliada como verdadeira segundo o padrão ANSI C.
