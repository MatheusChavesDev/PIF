O código é o seguinte: 

main()
{
printf("Linguagem C");
system("pause");
}

1. estão faltando as diretivas #include <stdio.h> e #include <stdlib.h>
2. falta o tipo da função main (int)
3. C é ima linguagem case sensitive, então o comando system("PAUSE") só vai funcionar se estiver escrito exatamente dessa maneira
4. falta o return 0; para encerrar a função main
